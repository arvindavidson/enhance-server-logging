# Reforger Mission Stats Parser

Generate comprehensive player and mission statistics from your Enhanced Server Logging mod JSON logs.

## Overview

This Python script analyzes JSON logs generated by the Enhanced Server Logging mod and produces:

- **Text Summary Report** - Quick overview of mission stats
- **Interactive HTML Report** - Beautiful, searchable leaderboards and statistics
- **CSV Exports** - Player and weapon data for further analysis (Excel, Google Sheets, etc.)

## Features

### Player Statistics
- Kills, Deaths, and K/D Ratio
- Teamkill tracking
- Weapon usage breakdown
- Connection/disconnection tracking
- Spawn counts
- Faction affiliations
- Playtime calculation

### Mission Statistics
- Mission duration
- Start and end times
- End reason (time limit, score limit, server restart, etc.)
- Total player count
- Overall kill/death statistics
- Faction performance

### Weapon Analytics
- Most used weapons
- Kills per weapon
- Kill share percentages

## Requirements

- **Python 3.6+** (usually pre-installed on most systems)
- No additional libraries required (uses Python standard library only)

## Usage

### Basic Usage

Point the script to a directory containing your JSON log files:

```bash
python3 stats_parser.py /path/to/ServerProfile/flabby/2025/12/10
```

### With Date Structure

If your logs are organized by date (YEAR/MONTH/DAY):

```bash
# Analyze logs for December 10, 2025
python3 stats_parser.py /path/to/ServerProfile/flabby/2025/12/10

# Analyze specific hour file
python3 stats_parser.py /path/to/ServerProfile/flabby/2025/12/10
```

### Recursive Search

Search all subdirectories for JSON files (useful for analyzing multiple days):

```bash
python3 stats_parser.py /path/to/ServerProfile/flabby/2025/12 -r
```

### Custom Output Name

Specify a custom output filename prefix:

```bash
python3 stats_parser.py /path/to/logs -o "SpecialOps_Mission_Alpha"
```

This generates:
- `SpecialOps_Mission_Alpha.txt`
- `SpecialOps_Mission_Alpha.html`
- `SpecialOps_Mission_Alpha_players.csv`
- `SpecialOps_Mission_Alpha_weapons.csv`

### PvE Mode

**Important:** Use the `--pve` flag for PvE (Player vs Environment) servers where players fight AI enemies:

```bash
python3 stats_parser.py /path/to/logs --pve -o "PvE_Mission"
```

**Why PvE mode is necessary:**

The Enhanced Server Logging mod only logs when **players die**, not when players kill AI enemies. This is a limitation of Arma Reforger's event system. In PvE mode, the parser:

- **Focuses on survival statistics** instead of kill counts
- Shows **deaths from AI, suicides, teamkills, and environmental deaths**
- Displays **AI weapons** that killed players (not player weapons)
- Sorts leaderboard by **fewest deaths** (survival ranking)
- Removes kill-based achievements (not applicable in PvE)

**PvE Mode Output Example:**

```
Total Deaths: 20
  - Deaths from AI: 14
  - Suicides: 4
  - Teamkills: 1
  - Other: 1

TOP AI WEAPONS (weapons that killed players)
1. PKM: 4 kills
2. RPK74M: 3 kills

PLAYER SURVIVAL LEADERBOARD (by fewest deaths)
#    Player Name     Deaths   Spawns   TKs
1    BestSurvivor    0        1        0
2    SecondPlace     1        2        0
```

**Without `--pve` flag:** The parser assumes PvP gameplay and tracks player kills/deaths between players.

**With `--pve` flag:** The parser focuses on player deaths from AI and survival statistics.

## Command Line Options

```
usage: stats_parser.py [-h] [-r] [-o OUTPUT] [--pve] log_directory

Parse Reforger Enhanced Server Logging JSON logs and generate statistics

positional arguments:
  log_directory         Path to directory containing JSON log files
                        (e.g., ServerProfile/flabby/2025/12/10)

optional arguments:
  -h, --help            Show help message and exit
  -r, --recursive       Recursively search for JSON files in subdirectories
  -o OUTPUT, --output OUTPUT
                        Output file prefix (default: mission_report)
  --pve                 PvE mode: Focus on survival stats (player deaths from AI)
                        instead of kill counts
```

## Log File Structure

The script expects JSON log files in this format:

### Directory Structure
```
ServerProfile/
└── flabby/
    └── YEAR/
        └── MONTH/
            └── DAY/
                ├── 14hr.ALL.json      # All logs for 14:00-15:00
                ├── 14hr.PLAYERS.json  # Player events only
                ├── 14hr.CHAT.json     # Chat logs
                ├── 15hr.ALL.json
                └── ...
```

### Log File Format
Each line in the JSON file contains:
```
TIMESTAMP {"function":"PlayerKilled","VictimPlayerName":"Player1",...}
```

## Troubleshooting

### "No JSON log files found"

**Cause:** The directory doesn't contain `.json` files

**Solutions:**
1. Verify the path is correct
2. Use `-r` flag to search subdirectories
3. Check that logging is enabled: `#log file TRUE`
4. Verify file extension is set to JSON: `#log extension JSON`

### "Permission denied"

**Cause:** No read access to log directory

**Solution:**
```bash
# Make script executable
chmod +x stats_parser.py

# Verify log directory permissions
ls -la /path/to/ServerProfile/flabby
```

### Empty or Incomplete Stats

**Cause:** Log files might be from different missions or incomplete

**Solutions:**
1. Ensure logs capture full mission lifecycle (GameStart, PlayerKilled, GameEnd events)
2. Verify mod is properly configured
3. Check that all players are being logged correctly

## Tips for Special Missions

### 1. Clear Logs Before Mission
Clear old logs before your special mission to avoid mixing data:
```bash
# Backup existing logs
mv /path/to/ServerProfile/flabby /path/to/ServerProfile/flabby_backup

# Fresh start
# (mod will create new directory automatically)
```

### 2. Enable All Logging
Ensure comprehensive logging in your config:
```
#log file TRUE
#log print TRUE
#log extension JSON
```

### 3. Post-Mission Analysis
Run the script immediately after the mission ends:
```bash
# Replace with your actual path
python3 stats_parser.py /path/to/ServerProfile/flabby/$(date +%Y/%m/%d) -o "Mission_$(date +%Y%m%d)"
```

## Advanced Usage

### Combining Multiple Missions

To analyze several missions together, use recursive mode on a parent directory:

```bash
# Analyze entire month of December
python3 stats_parser.py /path/to/ServerProfile/flabby/2025/12 -r -o "December_Operations"
```

### Automated Reports

Create a cron job or scheduled task to auto-generate reports:

```bash
# Add to crontab (runs daily at midnight)
0 0 * * * python3 /path/to/stats_parser.py /path/to/ServerProfile/flabby/$(date +\%Y/\%m/\%d) -o "Daily_Report_$(date +\%Y\%m\%d)"
```

### Integration with Discord/Web

Parse stats and pipe to other tools:

```bash
# Generate stats
python3 stats_parser.py /path/to/logs -o mission_stats

# Use the CSV output with other tools
cat mission_stats_players.csv | head -n 10  # Top 10 players
```
